## Feature Release

### New features and changes:

* **User Interface**
  * Straighten the current image in **Focus Point Viewer** [#385](https://github.com/FocusPointsLrC/Focus-Points/issues/385).  
    Enables you to level the image currently displayed in the Focus Point window. You have visual control of the result and the option to undo. This is the interactive version of the 'Straightening Images' batch process, so the same options and restrictions (e.g. supported cameras) apply.  
    Please refer to the user manual for a description of [Straightening Images](https://FocusPointsLrC.github.io/Focus-Points/docs/Focus-Points.html#24-straighten-images).
  * Remove "Loading Data - Calculating Focus Point" dialog [#380](https://github.com/FocusPointsLrC/Focus-Points/issues/380)  
  On fast computers, the progress dialog is barely noticeable — it's more like a brief flicker on the screen and can be perceived as distracting rather than informative. For this reason, the dialog has been removed. 
  * **Metadata Viewer**: Include Group information [#381](https://github.com/FocusPointsLrC/Focus-Points/issues/381)<br>Adds a third column to the Metadata Viewer to reflect the metadata group (e.g. IFD0, ExifIFDm XMP, Maker Notes) to which a tag belongs.

* **Bugfixes**
  * Windows: Focus Point display shows white space instead of the photo [#254](https://github.com/FocusPointsLrC/Focus-Points/issues/254)<br>
   
* **Camera Support**
  * Sony A7R VI
  * Panasonic DC-L10
  * in addition to the cameras supported by V3.3. [See here for full list](https://FocusPointsLrC.github.io/Focus-Points#supported-cameras)

* **Other**
  * Focus Info missing for DNG files converted from Canon CR3 [#308](https://github.com/FocusPointsLrC/Focus-Points/issues/308)  
  This issue will also be fixed on previous plugin versions as soon as Lightroom Classic is updated to version 15.4.
