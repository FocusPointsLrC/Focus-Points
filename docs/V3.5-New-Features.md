### Second Screen Mode

Currently, the plugin runs in Single Screen mode, which displays Focus Points in a window attached to Lightroom. While this window is open, Lightroom cannot be used.

Second Screen mode removes this limitation by displaying Focus Points in a separate window, allowing Lightroom to remain fully accessible. When the user selects a different image in Lightroom, the plugin should automatically calculate and display the corresponding focus points.

This feature is particularly useful in a multi-monitor setup, where Lightroom is used on one screen while Focus Points is displayed on another, automatically responding to changes in the Lightroom selection.

While the plugin largely retains its look and feel in Second Screen mode, there are a few important differences to note:

Keyboard shortcut operation of the plugin is restricted.
After loading a new image, keyboard shortcuts will not work until the shortcut input field is clicked again. This is generally not an issue in Second Screen mode, because users typically navigate and tag images directly in Lightroom.

The plugin window has a fixed width.
The Second Screen window remembers its position and size, which is particularly useful in a dual-screen setup. To provide a stable layout when displaying images with different aspect ratios, a fixed area is reserved for the photo view. The image is centered within this area, while the information panel remains aligned near the right edge of the window.

Windows: Instead of using Lightroom preview images, the plugin generates a temporary JPG file for rendering focus point overlays.
Exporting is necessary because Lightroom's preview generation is not sufficiently reliable in the Develop module for the plugin's requirements. Previously, this limitation was worked around by temporarily switching from the Develop module to the Library module. In Second Screen mode, however, such automatic module switching is not practical because the user continues working in Lightroom while the plugin updates independently.

Configuration:

To allow users to choose between the two operating modes, the plugin adds a Second Screen option to the current configuration:

Image

When the Second Screen option is enabled, Focus Points opens in a separate window. The size of this window is determined by the Size of plugin window and Aspect ratio settings.

Note: The Second Screen window remembers its last position and size. When changing the display size (S / M / L / XL / XXL), the dialog content may temporarily occupy less space than the current window size. This can result in additional empty margins on the right or bottom of the window. These can be removed by simply resizing the window manually once. The adjusted size will again be remembered automatically.

When the Second Screen option is disabled (the default setting), the plugin continues to operate in Single Screen mode as before.
