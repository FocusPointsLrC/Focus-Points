### Limitations
  * **'Second Screen' mode does not work on macOS secondary display with LrC 15.4 or earlier**.  
  When an image is switched, the plugin does not retain its position on the secondary display, instead swapping back to the main display on which LrC is running. A bug report has been filed with Adobe. <br>
  If you find this feature relevant, **please vote for this bug report** to increase its priority and improve its chances of being fixed:<br>
  https://community.adobe.com/bug-reports-674/p-mac-sdk-floating-dialog-does-not-reopen-on-second-screen-1628255
  <br><br>
  * **The 'Direct View' display method has known display issues on Windows with LrC 15.4 or earlier**.  
    'Direct View' has been the default display method on macOS. It is fast because it doesn't require JPG images to be written to disk and enhanced by drawing visualization rectangles onto them. Direct View also features live updates of the current photo. Any edits to the photo are immediately reflected in the plugin's display, which is useful in Second Screen mode.<br><br> 
    On Windows, the corner icons that visualize focus points, face or subject detection by overlaying the photo do not reveal the underlying image. Instead, transparent pixels are rendered using the background color of the Lightroom dialog box, resulting in visible rectangular artefacts around the overlay image.  A bug report has been filed with Adobe.<br>
  If you find this feature relevant, **please vote for this bug report** to increase its priority and improve its chances of being fixed:<br>
  https://community.adobe.com/bug-reports-674/p-windows-sdk-transparent-png-overlays-do-not-composite-correctly-in-overlapping-layouts-1628087
<br><br>
* **The 'Preview Image' and 'Exported Image' display methods are not yet available on macOS**.  
These features require the integration of ImageMagick/Mogrify for macOS. This is planned for one of the upcoming pre-releases. Once these display methods are available on macOS, users will benefit from clearer focus point markings and face and subject detection rectangles instead of corners by choosing one of these two methods instead of 'Direct View'.
